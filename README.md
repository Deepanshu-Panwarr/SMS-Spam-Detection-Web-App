SMS Spam Detection using Machine Learning

A Machine Learning based text classification project that detects whether an SMS message is Spam or Ham (Not Spam) using Natural Language Processing (NLP) techniques.

This project demonstrates practical implementation of:

Text preprocessing

Feature extraction (TF-IDF)

Model training

Performance evaluation

🚀 Project Objective

To build a classification model that can automatically identify spam SMS messages using supervised machine learning algorithms.

🧠 Tech Stack

Python

Pandas

NumPy

Scikit-learn

NLTK

Jupyter Notebook

📊 Dataset

SMS Spam Collection Dataset

Contains labeled SMS messages as spam or ham

⚙️ Project Workflow

Data Cleaning & Preprocessing

Lowercasing

Removing punctuation

Tokenization

Stopword removal

Feature Engineering

TF-IDF Vectorization

Model Training

Multinomial Naive Bayes

Model Evaluation

Accuracy Score

Confusion Matrix

Precision & Recall

📈 Results

The trained model achieves high accuracy on the test dataset and successfully classifies spam and non-spam messages.

Input:

"Congratulations! You won a free ticket. Call now!"
